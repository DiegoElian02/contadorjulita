# Saltillo · 1 de febrero de 2025

Coloca las fotos originales de la visita en esta carpeta con nombres como
`photo1.jpg`, `photo2.jpg`, `photo3.jpg`, `photo4.jpg`, etc.

El álbum detecta automáticamente todos los archivos `photoN.jpg`, `photoN.jpeg`,
`photoN.png` y `photoN.webp`, y los muestra por número (2 antes que 10).
La primera foto se utiliza como portada. Puedes añadir tantas como quieras.
